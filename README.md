# PM Quest — гейміфікований курс проєктного менеджменту

Vue 3 + TypeScript + Vue Router + Pinia + MDI. Контент береться з `pm-course.md` і розбирається під час збірки (`src/data/course.ts`).

Репозиторій поділено на дві частини:

```
frontend/   Vue-застосунок (деплой на GitHub Pages через .github/workflows/pages.yml)
backend/    API (деплой на Vercel, Root Directory = backend) — поки порожньо
```

```bash
cd frontend
npm install
npm run dev        # http://localhost:5174 (або інший вільний порт)
npm run typecheck
npm run build      # dist/
```

- **Мапа** (`/map`): 10 регіонів, 18 локацій-модулів (остання — «Арена Випробувань» з робочими ситуаціями) на звивистій стежці.
- **Квести**: кожен підрозділ `###` модуля стає квестом (+20 XP).
- **Сувій рефлексії**: питання «Перевір себе» з відповідями в Журналі (+30 XP).
- **Бос**: 5–6 питань (`src/data/quizzes.ts`), для перемоги потрібно ≥80% правильних (4 з 5 або 5 з 6). Перемога відкриває наступну локацію.
- **Скрині**: локацію пройдено → скриня із золотом і випадковим артефактом.
- **Герой**: 3 класи (Планувальник / Стратег / Комунікатор, +20% XP у своїх локаціях), рівні, звання, досягнення.
- **Кодекс**: глосарій скорочень у вигляді рун.
- **Практика** (`/practice`, окремий блок у сайдбарі): «Робочі ситуації» (модуль 18) і «Кейси з модулів» (уроки «Кейс з практики» з усіх модулів). Доступні одразу, незалежно від відкритих локацій; прогрес спільний із квестами.

Без входу застосунок працює в **режимі перегляду**: усі локації відкриті, прогрес не зберігається і запити на бекенд не надсилаються.
Після входу прогрес героя зберігається лише в хмарі (`/api/save` бекенду), синхронізація — `frontend/src/stores/sync.ts`.

## Структура `frontend/src/`

```
app/          App.vue (оболонка, навігація, HUD) і router.ts
components/   перевикористовувані UI-компоненти (MdiIcon, HeroAvatar, ToastStack, LevelUpModal)
composables/  логіка для екранів: useBossBattle, useWorldMap, useNextStep, useReadingProgress, useHeroPersistence
data/         статичний контент: світ (регіони, класи, боси, артефакти, досягнення) і тести босів
domain/       типи й чисті ігрові правила: рівні, серії днів, тести, лут, досягнення, прогрес героя
lib/          загальні утиліти: markdown, random, date
services/     зовнішні джерела: розбір pm-course.md, localStorage
stores/       Pinia: hero (прогрес), ui (сповіщення, модалка рівня)
styles/       глобальні стилі й токени палітри
views/        екрани маршрутів
```
